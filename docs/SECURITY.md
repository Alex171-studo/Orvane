# Confidentialité et limites de confiance

L’application est accessible sans invitation. Les clés Groq et OpenAI sont lues uniquement côté serveur, par ordre de priorité dans les secrets Streamlit, l’environnement puis le fichier .env local. Sur un site public, tout visiteur peut lancer une opération facturable.

Le quota de session réserve chaque tentative, échecs inclus. L’appel est déclenché par un bouton. Un verrou protège le traitement en cours et une empreinte permet la réutilisation d’un succès. Les retries natifs des SDK sont désactivés. Le réglage initial opère une seule tentative. Un plafond supérieur autorise uniquement la répétition d’un rejet 429 après délai exponentiel avec jitter. Un timeout, une rupture réseau ou un 5xx laisse l’issue financière incertaine et requiert une nouvelle décision explicite.

Le navigateur envoie le vocal au widget Streamlit en mémoire. Seul le bouton de transcription déclenche la transmission à Groq. Le JSON exporté ne contient aucun octet audio. Le contrôle vérifie le volume, le nom simple, l’extension, le MIME et le conteneur. Le chemin WAV décode l’en-tête PCM et lit une trame. MP3, M4A, OGG et WebM font l’objet de contrôles de signatures. Un conteneur reconnu peut encore être illisible pour le décodeur distant. Le SDK reçoit un nom générique et les octets. Les journaux applicatifs enregistrent des identifiants de traitement, le modèle, la durée, l’état et la classe d’erreur. Garder les traces détaillées HTTP/SDK désactivées en exploitation.

Les instructions de la note sont des données. Le modèle ne peut appeler aucun outil. L’interface affiche le texte utilisateur dans des widgets texte ou des tableaux. Le balisage visuel est statique et les données sont échappées pour ReportLab. Les incertitudes et les informations sans preuve sont présentées à la revue humaine.

L’archive exportée est un fichier **en clair** contenant notes et valeurs d’audit. La partager uniquement avec les personnes autorisées. Son import valide la cohérence, sans signature d’origine. Les rapports importés ne constituent pas une preuve d’identité du validateur. La perte du WebSocket, un redémarrage ou la mise en veille peut effacer la session. Seule une archive préalablement exportée permet une restauration.

Une nouvelle session possède un nouveau quota. Un service multiutilisateur durable nécessite une authentification individuelle, des droits par chantier, des quotas globaux, un stockage persistant et une politique de conservation. Régler également les limites de dépense chez les fournisseurs. L’envoi à Groq ou OpenAI relève des conditions, contrôles de données et tarifs du compte utilisé. OpenAI reçoit `store=False`.
